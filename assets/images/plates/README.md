# ColorSightTest Image Assets

This directory should contain the color plate test images.

## Required Images

The app expects 12 color plate images named:
- `plate_01.png` through `plate_12.png`

## Image Specifications

- **Format**: PNG
- **Size**: Recommended 800x800 pixels (square)
- **Type**: Ishihara-style color vision test plates

## Important Notice

Due to copyright restrictions, this repository does not include actual Ishihara test plates. You have several options:

### Option 1: Use Placeholder Images
For development and testing purposes, you can use solid color gradient images. The app already includes fallback placeholders when images are missing.

### Option 2: Create Custom Test Plates
You can create your own color vision test plates using image editing software. Search for "Ishihara plate generator" or "color blindness test generator" for tools.

### Option 3: Purchase Licensed Images
For a production app, you should purchase properly licensed Ishihara test plate images from authorized sources.

### Option 4: Use Public Domain Alternatives
Some simplified color vision tests are available in the public domain. Research carefully to ensure proper licensing.

## Creating Placeholder Images

If you want to test the app without actual test plates, you can:

1. Use any 800x800 PNG images
2. Name them plate_01.png through plate_12.png
3. Place them in this directory
4. The app will display them (though they won't test color vision accurately)
